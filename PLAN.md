# Part A: Sprint Planning

## 1. User Stories & 2. Acceptance Criteria

**Story 1 (Resident)**
*   User Story: As a resident, I want to see the current water level and its color-coded status so that I immediately know if my area is safe.
*   Acceptance Criteria:
    *   The page displays the current water level in centimeters.
    *   The text color automatically changes to green (Normal, <100 cm), orange (Alert, 100-149 cm), or red (Danger, >=150 cm).

**Story 2 (Barangay Official)**
*   User Story: As a barangay official, I want to view a chart and table of recent readings so that I can track how fast the water is rising over the last hour.
*   Acceptance Criteria:
    *   The UI displays a line chart mapping the latest readings.
    *   A table below the chart accurately lists the 10 most recent readings.

**Story 3 (Resident)**
*   User Story: As a resident, I want to read an automated advisory in English and Filipino so that I can easily understand what emergency actions to take.
*   Acceptance Criteria:
    *   Clicking the "Generate advisory" button produces a bilingual advisory of 3 sentences or fewer.
    *   If the AI generation fails, a pre-written fallback advisory is displayed instead.
